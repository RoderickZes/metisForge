# Ejercicios - LAB-001

## Introducción

Los ejercicios son el corazón de Metis Forge.

Cada uno representa una etapa del proceso de aprendizaje y fue diseñado para desarrollar habilidades prácticas, no solamente memorizar comandos.

No se espera que completes un ejercicio rápidamente.

Se espera que entiendas qué estás haciendo y por qué.

---

# Cómo trabajar los ejercicios

Cada ejercicio sigue la misma estructura:

1. Introducción al problema.
2. Conceptos teóricos necesarios.
3. Objetivos.
4. Actividades prácticas.
5. Preguntas para reflexionar.
6. Evidencia que debe entregarse.

No avances al siguiente ejercicio hasta comprender el actual.

En Metis Forge el objetivo no es terminar primero.

El objetivo es construir conocimiento sólido.

---

# Orden recomendado

Los ejercicios deben realizarse en el siguiente orden:

00 — Entendiendo el entorno de trabajo

01 — Explorando Linux

02 — Usuarios y grupos

03 — Permisos

04 — Administración remota mediante SSH

05 — Logs y observabilidad

Cada ejercicio utiliza conocimientos adquiridos en los anteriores.

---

# Evidencia

Durante cada ejercicio registra:

- Comandos utilizados.
- Capturas de pantalla cuando corresponda.
- Problemas encontrados.
- Soluciones aplicadas.
- Explicaciones con tus propias palabras.

Al finalizar el laboratorio deberías ser capaz de explicar cada decisión que tomaste.

---

# Filosofía

En Metis Forge no buscamos que repitas comandos.

Buscamos que desarrolles criterio técnico.

Si en algún momento no entendés por qué ejecutaste un comando, ese es un buen momento para detenerte, investigar y hacer preguntas.

Comprender siempre tiene prioridad sobre avanzar.
