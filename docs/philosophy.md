# Metis Forge Philosophy

## Purpose

Metis Forge is an open-source educational platform focused on teaching infrastructure, Linux and cybersecurity through practical, reproducible laboratories.

The objective is not only to deploy technologies, but to understand why they exist, how they communicate, how they are operated and how they can be secured.

Metis Forge promotes understanding over memorization, encouraging learners to build real environments, investigate their behavior and document every technical decision.

---

# Core Principles

## Understand before deploying

Technology should never be used blindly.

Every component should have a clear purpose, documented alternatives and an understanding of the problems it solves.

Configuration without understanding is not the goal.

---

## Learn by building

Knowledge becomes meaningful when applied.

Every laboratory should require learners to build, configure, troubleshoot and improve a real environment rather than simply reading about it.

Learning happens through practice.

---

## Documentation is part of the system

A system without documentation becomes difficult to maintain, troubleshoot and improve.

Documentation is not an extra task.

It is part of the infrastructure itself.

Every laboratory should produce technical evidence explaining not only *what* was done, but also *why*.

---

## Security by design

Security should never be an afterthought.

It must be considered from the first design decision and continuously improved throughout the lifecycle of the system.

Every laboratory should encourage thinking about risks before implementing solutions.

---

## Accessible learning

Quality education should be accessible.

Metis Forge prioritizes open-source technologies, reproducible environments and hardware requirements that allow as many people as possible to participate.

Whenever possible, laboratories should provide multiple execution modes (for example, Docker and Virtual Machines) without changing the learning objectives.

---

## Mistakes are part of learning

Experimentation is encouraged.

Errors are expected.

Troubleshooting is one of the most valuable skills an infrastructure professional can develop.

Students should investigate problems, understand their causes and document the lessons learned instead of simply following instructions.

---

## Knowledge should be shared

Learning becomes stronger when it is explained to others.

Metis Forge encourages students to teach, document, collaborate and contribute back to the community.

Every learner can eventually become an instructor.

---

## Continuous improvement

Infrastructure evolves constantly.

Learning should never stop.

Metis Forge is designed as a long-term learning journey where each laboratory builds upon previous experience and prepares learners for increasingly complex systems.

---

# Educational Lifecycle

Every laboratory follows the same educational lifecycle:

```
Understand
      ↓
Design
      ↓
Deployment
      ↓
Operation
      ↓
Security Analysis
      ↓
Hardening
      ↓
Documentation
```

The objective is not simply to complete a laboratory.

The objective is to understand how real-world infrastructure is designed, deployed, operated, secured and documented.
