# Suggested SPDX headers

Use these short headers in new files when practical.

## Software files

```text
SPDX-FileCopyrightText: 2026 Rodrigo Zárraga and Metis Forge contributors
SPDX-License-Identifier: AGPL-3.0-or-later
```

For shell, Python, YAML and similar formats, prefix each line with the format's comment marker.

## Educational Markdown files

```text
SPDX-FileCopyrightText: 2026 Rodrigo Zárraga and Metis Forge contributors
SPDX-License-Identifier: CC-BY-SA-4.0
```

In Markdown, the header may be placed inside an HTML comment.
