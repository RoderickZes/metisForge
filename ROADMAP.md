# Metis Forge Roadmap

This roadmap describes the planned evolution of Metis Forge.

Each laboratory builds upon previous knowledge and follows the same educational philosophy:

Understand → Build → Operate → Secure → Document

The roadmap may evolve as the project grows.

---

# Phase 1 — Linux Fundamentals

Objective

Build a solid foundation in Linux system administration.

Planned laboratories

- LAB-001 — First Linux Server
- LAB-002 — Linux Filesystem
- LAB-003 — Users and Groups
- LAB-004 — Permissions
- LAB-005 — Services and Processes
- LAB-006 — SSH Administration
- LAB-007 — Logs and Troubleshooting

---

# Phase 2 — Networking Fundamentals

Objective

Understand how systems communicate.

Planned laboratories

- IP Addressing
- Routing Basics
- DNS
- DHCP
- HTTP / HTTPS
- Firewalls
- Packet Analysis

---

# Phase 3 — Infrastructure

Objective

Deploy and manage modern infrastructure.

Planned laboratories

- Docker Fundamentals
- Docker Networking
- Docker Compose
- Reverse Proxy
- Nginx
- Apache
- Database Servers

---

# Phase 4 — Operations

Objective

Operate infrastructure reliably.

Planned laboratories

- Monitoring
- Centralized Logging
- Backups
- Automation
- Scheduling
- Performance Analysis

---

# Phase 5 — Security

Objective

Protect infrastructure against common threats.

Planned laboratories

- Linux Hardening
- SSH Hardening
- Firewall Configuration
- Vulnerability Assessment
- Incident Response
- Security Auditing

---

# Phase 6 — Infrastructure as Code

Objective

Learn reproducible infrastructure.

Planned laboratories

- Git Fundamentals
- Bash Automation
- Infrastructure as Code
- Configuration Management
- CI/CD Basics

---

# Phase 7 — Cloud & Modern Platforms

Objective

Introduce cloud-native concepts.

Planned laboratories

- Virtual Machines
- Cloud Networking
- Object Storage
- Containers in the Cloud
- Kubernetes Fundamentals

---

# Phase 8 — Capstone Project

Objective

Design, deploy, secure and document a complete infrastructure.

Students will be expected to:

- Design the architecture
- Deploy the environment
- Configure networking
- Secure the systems
- Monitor the infrastructure
- Document technical decisions
- Present evidence of their work

---

## Educational Philosophy

Every laboratory follows the same lifecycle:

Understanding

↓

Design

↓

Deployment

↓

Operation

↓

Security Analysis

↓

Hardening

↓

Documentation

---

## Learning Modes

Every laboratory should be runnable in two different ways whenever possible:

- Quick Mode (Docker)
- Professional Mode (Virtual Machine)

Both execution modes should produce equivalent learning outcomes.
