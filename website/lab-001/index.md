# LAB-001 · First Linux Server

> Estado: **Estable · Versión 1.0**

El primer laboratorio de Metis Forge enseña los fundamentos de una administración Linux moderna mediante un recorrido práctico, reproducible y documentado.

## ¿Qué vas a aprender?

- Comprender cómo funciona una computadora.
- Diferenciar hardware y software.
- Utilizar la terminal con confianza.
- Explorar el sistema de archivos de Linux.
- Administrar usuarios y grupos.
- Comprender permisos y propiedad.
- Conectarte mediante SSH.
- Investigar registros del sistema.
