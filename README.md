# Metis Forge

Metis Forge is an open-source educational platform focused on teaching infrastructure, Linux and cybersecurity through practical, reproducible laboratories.

Instead of only learning how to exploit vulnerabilities, learners understand how systems are designed, deployed, operated and secured.

The project emphasizes understanding over memorization and encourages students to build real environments while documenting every technical decision.

---

# Who is Metis Forge for?

Metis Forge is designed for multiple audiences.

Choose the path that best matches your goal.

## I want to learn Infrastructure & Cybersecurity (Student)

Start here:

```
labs/LAB-001-first-linux-server/
```

Read the laboratory `README.md` and follow the exercises in order.

This is the recommended starting point for anyone using Metis Forge as a learning platform.

---

## I want to teach using Metis Forge (Instructor)

Start here:

```
labs/LAB-001-first-linux-server/teacher/
```

Instructor materials include lesson plans, instructor guides and teaching notes designed for classrooms, workshops and study groups.

---

## I want to contribute to Metis Forge (Contributor)

Start here:

```

```

This directory contains the project's engineering documentation, including:

- Architecture
- Project philosophy
- Architecture Decision Records (ADRs)
- Laboratory standards
- Development guidelines

If you plan to contribute code, documentation or new laboratories, this is your starting point.

# Learning Philosophy

Every laboratory follows the same learning lifecycle.

```
Understanding
      │
      ▼
Design
      │
      ▼
Deployment
      │
      ▼
Operation
      │
      ▼
Security Analysis
      │
      ▼
Hardening
      │
      ▼
Documentation
```

Students are encouraged to understand **why** a system works before learning **how** to configure it.
